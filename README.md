<h1>Contação de Histórias</h1>
<p>Desenvolvimento web para atender uma demanda de evento da instituição Iris Célia Cabanellas Zannini (ICCZ). Contando com a implementalçao de banco de dados, o projeto visava armazenar os dados de alunos e convidados que deveriam avaliar o evento pelo site como forma de avaliação bimestral</p>
